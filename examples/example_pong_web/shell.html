Pong on Dear ImGui

The classic game running inside Dear ImGui — the immediate-mode GUI library that powers debug overlays, level editors, and tooling in countless games and engines — compiled to WebAssembly via Emscripten. The exact same C++ source builds natively or runs in your browser; paddles, ball, scores, and the Settings window all flow through ImGui’s draw API into WebGL.

Originally a Lua script for UEVR (Unreal Engine VR), ported to C++ and tuned here — bounce-aware AI prediction, live difficulty sliders, and a few rough edges still showing through.

Press SPACE, move with W/S or ↑/↓. Tweak the AI from the Settings menu.
