Mini-games on Dear ImGui

Two small games — Pong and Tetris — running inside Dear ImGui, the immediate-mode GUI library that powers debug overlays, level editors, and tooling in countless games and engines, compiled to WebAssembly via Emscripten. The exact same C++ source builds natively or runs in your browser; every paddle, block, score, and Settings window flows through ImGui’s draw API into WebGL.

Pong started as a Lua script for UEVR (Unreal Engine VR), then ported to C++ and tuned here — bounce-aware AI, live difficulty sliders. Tetris is built fresh in the same shape: a single self-contained function with a menu bar, settings window, DAS/ARR input feel, and a ghost piece.

Pong: SPACE start, W/S or ↑/↓ move.   Tetris: A/D move, W rotate, Z CCW, S soft drop, SPACE hard drop, P pause.
